# Project B working rules

This repository is the public, experimental sandbox rootfs portability project. Keep private investment research out of it.

Read `.agents/skills/project-b-model-routing/SKILL.md` before implementation work. The user authorizes model-specific subagent delegation under that policy.

Deliver the controlled kind -> registry -> fresh kind and Docker proof before expanding the CLI. Rootfs only, Linux/amd64, containerd overlayfs, one quiesced container. No controllers, SaaS, UI, GPU, RAM checkpoints, or user-volume snapshots.

Never claim a test passed without its actual result. Preserve source Pods on snapshot failure. Only the coordinating agent operates shared Docker/kind resources. Keep generated images, upstream checkouts, artifacts, kubeconfigs and tool binaries out of Git. No automatic publishing or upstream messages.
